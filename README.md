# Fase 1 | Análisis
Se conceptualizó "Los Exploradores del Saber", un videojuego educativo en consola 
de Python diseñado para niños de 8 a 12 años que busca fomentar la comprensión lectora
y la cultura general a través de cuentos, Arte ASCII, minijuegos y un espacio creativo 
de construcción con matrices y archivos
# Fase 2 | Diagrama de Flujo
Esta fase fue primordial para comprender todo el panorama del videojuego y estructurar 
su lógica, mapeando la navegación por países, la secuencia de lectura y preguntas, 
la validación de datos y la persistencia de archivos antes de codifica
# Fase 3 | Código
Se creó el código tomando como referencia el diagrama para tomar las decisiones 
correctas de arquitectura, programando en Python funciones modulares, efectos de 
texto, tuplas inmutables, manejo de excepciones y la lectura/escritura 
del Planeta Creativo
# Fase 4 | Presentación Final
Se preparó la entrega final del proyecto y se creó la carpeta correspondiente en 
GitHub utilizando las credenciales del instituto para gestionar el repositorio, 
asegurando la documentación y el correcto funcionamiento del sistema
